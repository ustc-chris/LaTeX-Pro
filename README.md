# LaTeX Pro · 0.11.0

面向长文档的 VS Code 工作台，提供文档结构、写作、参考文献、AI 和版本管理页面。参考文献支持项目 BibTeX 浏览、检索、引用位置与条目编辑。

## 安装与开始

1. VS Code 扩展面板的 `…` 菜单 → 从 VSIX 安装 → 选择 `latex-pro-0.11.0.vsix`。
2. 打开单文件夹项目，运行 `LaTeX Pro: 打开工作台`，点击“绑定项目”。未绑定时仅查看源码。
3. 在右上角设置的“项目”中选择主入口和项目名称。没有项目 JSON 时，设置默认全局生效；已有 `.vscode/settings.json` 时保存到项目，不自动创建项目 JSON。
4. 在导航台选择内容，使用保存按钮或 Cmd/Ctrl+S 写回源码。也可通过 tex 标签页的“重新打开编辑器的方式”打开工作台。

示例：打开 `examples/demo` 文件夹，以 `main.tex` 为入口。示例使用 XeLaTeX 编译。

## 写作

- 单行工具栏切换源码/快速预览、内容层级，以及源码/源码+PDF/PDF布局。
- 源码采用 Monaco 高亮；按文件、章节和片段编辑。全文按主入口展开标准 input/include 引用，支持源码及快速预览编辑；文件分界受保护，修改按原文件保存。
- 快速预览正文可直接编辑，点击公式、图片和表格修改对应 LaTeX。label/ref 显示小图标，悬停查看、点击修改。
- 支持常见正文、PNG/JPEG/SVG、简单 tabular、KaTeX 公式。简单表格的纯文字单元格可直接编辑，复杂单元格通过表格源码浮窗编辑。PDF 图片支持按需生成第一页预览；复杂宏和排版在原处保留源码入口，预览不保证正式排版精度。
- 导航台可调宽，拖到左边缘隐藏；通过边缘光带拖出或点击恢复，使用“章/节/目/段”控制深度；右键提供新标签页、改标题、单目录视图。选中后 Enter 原位修改标题；文件项可在同目录重命名，并更新标准 input/include 引用。
- 左下角浮动字数统计可悬停查看详情；右下角彩色标签可点击修改。
- 全文搜索支持 macOS `⌘⇧F`、Windows/Linux `Ctrl+Shift+F`，显示上下文并精确跳转，最多500条。
- 源码与快速预览使用 Cmd/Ctrl+F 开关紧凑搜索替换栏，支持大小写、全字、正则、单次和全部替换。
- 非编辑区域支持横向触控板前进/后退，并显示方向箭头。Option+←/→ 保留原生单词移动与选区逻辑；编辑器和输入框内不拦截导航手势。
- Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z 撤销/重做标题、文件重命名、状态和标签修改；编辑区内保留文字撤销，设置不进入历史。
- 源码字体大小、字体与基础语法颜色跟随 VS Code。
- 未保存时禁止切换范围，提供草稿暂存与外部修改冲突检测。

## PDF

PDF.js 官方查看器提供高清渲染、上下连续分页、超链接，以及触控板平移和捏合缩放。底部浮动工具条始终显示页码和缩放，页码可原位输入跳转。刷新和编译位于 PDF 左上角；右上角独立“🔗自动跟随”控制源码同步。

自动读取项目根目录下与入口同名的 PDF，例如 `src/paper.tex → paper.pdf`，变化后自动刷新。自动跟随默认开启，关闭后独立浏览并在刷新时尽量恢复页内位置；右键“定位源码”或 Cmd/Ctrl+单击跳回最小内容范围。

编译在 JSON 中定义工具和配方，编译台可选择配方并查看输出；需要安装对应的 TeX 工具。输出默认位于项目根目录，可调整到项目内的其他目录，PDF 与 SyncTeX 同步使用该目录。

## 标记与状态

```tex
\section{背景}
% !lp meta {"status":"draft","tag":"AI初稿"}
% !lp begin {"id":"intro-01","title":"研究动机","status":"draft","tag":"人工初稿","time":"2026-11-13T12:00:00Z","note":"交代目标"}
正文可以包含多个段落，也可以是表格或公式。
% !lp end
```

| 字段 | 含义 |
| --- | --- |
| id | 项目内唯一片段标识，移动时保留 |
| title | 片段标题 |
| note | 简要说明 |
| status | todo 待编写（灰）、draft 初稿（橙）、final 定稿（蓝） |
| tag | 手动显示文字，例如 AI初稿、人工初稿、定稿-v1113 |
| time | 确认标签时写入 ISO 时间；普通正文修改不更新 |

兼容旧 ai-draft/human-draft/review/done 状态。章节拥有自身标签，不从子内容汇总。未标记文件停留在文件层级并显示“未标记”；入口引用的结构文件保留章节以连接跨文件层级。片段不嵌套；章节包含下级章节与片段。非法、不完整或重复标记产生扫描提示。

## 文档结构与设置

地图用多列圆角矩形表达包含关系。框的大小和位置不随缩放重排；按可用屏幕空间显示标题、标签、摘要，远看填充色、近看边框色。单击选择、双击打开写作，右键提供编辑、AI 修改和加入编辑需求。

支持触控板平移和捏合缩放；缩略图仅在移动或缩放时快速淡入，停止三秒后缓慢淡出。统计通过按钮弹出，不展示状态分类计数。

设置分“项目 / 视图 / AI / 关于”。普通设置即改即存；入口文件和编译配置单独确认。支持亮色、暗色、跟随 VS Code 主题与自定义编译程序。扫描限2000个 tex 文件，每个最大2 MB；不处理任意 TeX 宏展开。

## AI 与修改审阅

先安装本机 Codex CLI 并执行 `codex login`。路径自动查找，也可在设置 → AI 中指定。插件按需启动 Codex App Server，读取本机登录与模型列表，保存和恢复本项目会话。

- 顶部 AI 页面与写作右侧 AI 栏共享会话、模型和思考强度。默认模型显示实际名称，强度选项来自 Codex 支持列表。
- 导航台、地图右键和编辑器右键可提出修改要求。编辑器自有菜单提供复制、粘贴、剪切、AI 修改、提交修改需求；有有效选区时仅修改所选源码。底部“描述修改需求”文本框仅在源码区展开，使用“AI修改（立即）”或提交修改需求。
- 待提交需求在右上角黄色清单中查看、修改、删除和批量提交，支持附加整体要求。
- AI 在只读沙箱中生成候选文本。点击“对比”在应用内打开增删行差异与预览对比，再按文件应用或拒绝。原文变化时阻止覆盖。
- 清单保留加入时的源码；提交前原文已变则要求重新加入。失败或中断时不清空需求。

## 版本管理

顶部 Git 图标打开应用内版本页面。只使用绑定项目根目录的 `.git`，不查找或复用父目录仓库。首次绑定/启动项目时，没有自己的仓库则创建仓库并提交 `init`；已有仓库保留原历史，后续由用户填写说明、手动提交全部已保存的改动。

默认 `.gitignore` 忽略 LaTeX 中间文件、缓存和编辑器临时文件，保留 PDF、图片、正文及 `.bbl`；已有规则不覆盖。版本页面可编辑忽略规则，查看改动、最近 40 次提交，选择历史版本与当前已跟踪文件对比。文字对比限 2 MB，二进制文件仅提示无法显示文字差异；当前不提供分支、远程推送或回滚。Git 需要本机安装。若未设置作者身份，单次提交使用 LaTeX Pro / latex-pro@local.invalid，不修改全局 Git 身份。

项目配置文件 `.vscode/settings.json` 可缺省，使用默认设置；真实的 JSONC 格式错误在扫描提示中显示路径和行号。Codex 可选配置读取失败会记入输出，模型列表仍可使用。

## 开发

需要 VS Code 1.110+、Node.js 22+。所有运行资源随 VSIX 打包，不依赖 CDN。

```sh
npm ci
npm run check
npm test
npm run test:dom
npm run test:ui
npm run package
```

`npm run test:dom` 验证页面交互和写回，使用模拟源码/PDF 渲染器，并独立验证 PDF 控件跳页、关闭跟随及刷新位置保留；`npm run test:codex` 会调用本机已登录 Codex 做一次真实候选生成。

完整 UI 测试需要 Chrome/Playwright Chromium 和 pdflatex，可通过 `LATEX_PRO_TEST_PDFLATEX` 指定完整路径。按 F5 启动扩展开发宿主。

0.3 将 Monaco、预览、PDF 和地图按需加载并缓存扫描结果，减少启动等待。底层使用 VS Code API、React、Monaco、unified-latex、KaTeX、PDF.js、React Flow。代码采用 MIT，第三方组件保留原许可证。

0.3.1 修复工作台持有已关闭文档导致保存失败的问题。保存前按 URI 重新取得文档，仍核对用户看到的版本和正文，以防外部修改被覆盖。全文汇总与搜索改为读取文件，不批量打开不可见原生编辑器。输出面板选择“LaTeX Pro”可查看扫描、webview ready、editor ready 各阶段耗时；它们分别测量扫描时间与面板创建后的准备时间。



## 独立扩展宿主


独立宿主会增加一个扩展宿主进程及其内存、启动开销；该配置属于 VS Code 的实验功能。它可减少同一宿主内其他扩展的阻塞影响，无法隔离主进程、系统 I/O 或独立宿主自身触发的系统证书读取。实际分配须通过日志或 VS Code 进程资源管理器核验，配置值不代表已经运行在独立进程。

执行 `LaTeX Pro: 移除工作区独立宿主配置` 可移除本扩展的工作区分组并重载。该命令保留其他扩展分组和用户级配置；如用户级也指定了分组，会继续生效。两个命令均不修改证书设置。

0.4.4 默认自动配置独立宿主：首次打开 LaTeX Pro 或绑定项目时，自动检查当前工作区分组；首次写入后提示保存内容并重载窗口。已有独占分组不重复写入、不重复提示，也不会自动重载窗口。执行“移除工作区独立宿主配置”会同时关闭 `latexPro.autoHostIsolation`，避免下次启动重新添加；手动“配置独立宿主”会重新开启自动管理。此选项可在 VS Code 设置中关闭，插件不更改系统证书设置。

0.4.5 调整首装/更新后的初始化顺序：在激活阶段提前创建启动页，首个打开指令复用该面板；页面先以内嵌样式显示框架、“首次初始化”、阶段和等待时间，再加载完整资源。项目扫描、主题读取、自动宿主配置及 AI 历史恢复推迟到界面显示后。首次完成标记包含版本与可用的安装时间戳。若 VS Code 在激活本扩展之前已阻塞，插件仍无法提前绘制；需通过实际重装验证启动页是否赶在宿主阻塞前显示。


0.5.0 加入项目内 Git 页面与对比、自有编辑菜单、源码区需求输入、共享模型与思考强度，调整 PDF 浮动控件、侧栏边缘拖拽、预览行距和标题背景渐变。新增真实临时 Git 仓库测试、AI 协议强度/选区测试、项目配置检查，以及 Git 页面/内嵌对比交互回归。完整浏览器渲染仍需在正常桌面环境运行 `npm run test:ui`。

0.5.1 调整文档结构标题：层级改为标题前的小标签，subsection 显示 sub sec，普通段落仅显示“段”；空间不足时隐藏层级标签。遮罩贴合框的顶部内边缘，复用矩形填充色，仅在父标题/状态与下层实际文字重叠时显示，向下渐变透明。文字与状态位于遮罩上方。文字测量在初次显示、缩放、布局/字体/容器尺寸变化时执行，平移不触发测量或方块重绘。
